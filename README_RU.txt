TSA PREMIUM Launcher — исходный проект

Цель: Android 8.0 (API 26+), экран 1024x600, альбомная ориентация.

Что уже реализовано:
- стартовый экран в тёмном премиальном стиле;
- часы;
- плитки навигации, музыки, телефона и настроек;
- список установленных приложений;
- регистрация приложения как Android HOME launcher.

Важно:
Это исходный проект, а не готовый APK. Для сборки нужен Android Studio на компьютере:
1. Установить Android Studio и Android SDK.
2. Открыть папку TSA-PREMIUM как проект.
3. Дождаться синхронизации Gradle.
4. Build → Build Bundle(s) / APK(s) → Build APK(s).
5. Полученный app-debug.apk перенести на магнитолу и установить.

На самой магнитоле при первом запуске Android может предложить выбрать приложение главного экрана. Выбрать TSA PREMIUM.

Примечание: названия пакетов Яндекс Навигатора, 2ГИС и музыкального плеера могут отличаться на конкретной прошивке. Если приложение не открывается, оно появится в списке «Все приложения» (если Android предоставляет его как запускаемое приложение); затем настроим точные действия по установленным приложениям.
