СБОРКА APK С IPHONE ЧЕРЕЗ GITHUB ACTIONS

1. Откройте github.com в Safari и войдите в аккаунт (или создайте его).
2. Создайте новый репозиторий. Название: TSA-PREMIUM. Для простоты можно выбрать Public.
3. Загрузите содержимое папки tsa_premium из этого архива в корень репозитория. Важно: загружать именно содержимое папки, чтобы app, build.gradle, settings.gradle и .github оказались в корне.
4. Откройте вкладку Actions репозитория. Если GitHub попросит разрешить Actions, подтвердите.
5. В списке workflows выберите Build TSA PREMIUM APK и нажмите Run workflow.
6. Дождитесь зелёной галочки. Откройте завершённый запуск, пролистайте до Artifacts и скачайте TSA-PREMIUM-debug-apk.
7. Распакуйте скачанный ZIP в приложении «Файлы» на iPhone. Внутри будет app-debug.apk.
8. Передайте APK на магнитолу удобным способом (USB-флешка, если магнитола читает её, либо облако/мессенджер) и установите.

Примечание: это debug APK для первоначального тестирования. Сборка не гарантирует, что все функции будут работать на конкретной прошивке; после установки проверим запуск, масштаб и приложения.
